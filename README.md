# Atuin Threads, a Herdr mod

A panel for the [Herdr](https://herdr.dev) app that lists the coding-agent sessions
[Atuin](https://atuin.sh) captured as threads, and resumes one in a new tab when clicked.

Install: copy `mods/atuin-threads/` into `~/.config/herdr-app/mods/`, merge `keys.json` into
yours, press `cmd-shift-t`. Needs `atuin` 18.24.3 or later with threads turned on
(`atuin config enable threads`). [RECIPE.md](RECIPE.md) is the brief to build it from scratch.
